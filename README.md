## ✨ Features & Architecture

- **🌌 Interactive Neural Network Background**: A 60 FPS HTML5 Canvas particle & neural synapse simulation that dynamically connects and reacts to cursor coordinates.
- **⚡ Obsidian Cyberpunk Theme**: Curated dark glassmorphism design system (`backdrop-filter: blur(16px)`), neon gradients (electric indigo, cyan, emerald), and 3D card tilt physics.
- **🧪 Live AI Lab (Interactive In-Browser Demos)**:
  1. **Heart Disease RNN Predictor**: An interactive simulation of the 95% accuracy RNN model. Visitors can adjust Age, Blood Pressure, Cholesterol, and Max Heart Rate to see real-time inference, SVG radial risk gauge updates, and feature contribution bars.
  2. **LangGraph ReAct Agent Simulator**: A simulated conversational clinical console demonstrating the 5-tool autonomous reasoning loop (Log, Edit, Search, Retrieve, Suggest Talking Points) powered by Groq LLM (gemma2-9b-it).
- **💻 Developer Terminal CLI (`ai-terminal`)**: An authentic retro bash command-line interface. Visitors and recruiters can type commands like `bio`, `skills`, `projects`, `predict`, `agent`, `contact`, `resume`, or `sudo hire` for interactive terminal exploration.
- **🗂️ Filterable Technical Skills Matrix**: Instant category filtering across AI/ML, Deep Learning & CV, Programming, Full-Stack, and Tools.
- **📄 Printable / Downloadable Resume Modal**: Built-in, clean, single-sheet printable resume modal with quick print-to-PDF support.
- **🔊 Web Audio API Sound Effects**: Subtle, futuristic audio feedback on button clicks and actions, complete with a persistent mute toggle button.
- **📱 100% Mobile & Tablet Responsive**: Optimized navigation drawer, responsive grids, touch-friendly sliders, and fast loading times.

## 🚀 How to Run Locally

You can open and view the portfolio locally using any browser:

### Option 1: Direct File Open
Simply double-click `index.html` or right-click and choose **Open with Browser (Chrome/Edge/Firefox)**.

### Option 2: Local HTTP Server (Recommended)
Using Python (pre-installed on most systems):
```bash
python -m http.server 3000
```
Or with Node.js `npx`:
```bash
npx serve .
```
Then visit [http://localhost:3000](http://localhost:3000) in your browser.

## 📦 How to Upload to GitHub & Deploy Live with GitHub Pages

Follow these simple steps to push this code to your GitHub account:

### Step 1: Initialize Git and Commit
Open PowerShell or your terminal in this directory (`g:\anti`):
```bash
git init
git add .
git commit -m "feat: initial release of Lakshmikanth Manibolu AI/ML Engineer portfolio"
```

### Step 2: Create a New GitHub Repository
1. Go to [https://github.com/new](https://github.com/new).
2. Repository name: `portfolio` (or `Lakshmikanthmanibolu.github.io` if you want it as your primary GitHub user page).
3. Set visibility to **Public**.
4. Leave "Add a README file" unchecked (you already have this one).
5. Click **Create repository**.

### Step 3: Push to GitHub
Run the following commands (replace `portfolio` with your chosen repo name):
```bash
git branch -M main
git remote add origin https://github.com/Lakshmikanthmanibolu/portfolio.git
git push -u origin main
```

### Step 4: Turn on GitHub Pages (Free Instant Hosting)
1. On your GitHub repository page, click **Settings** (top right tab).
2. In the left sidebar, click **Pages**.
3. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main** / folder: **/(root)**
4. Click **Save**.
5. Wait 1-2 minutes! Your portfolio will be live at:
   👉 **`https://Lakshmikanthmanibolu.github.io/portfolio/`**
